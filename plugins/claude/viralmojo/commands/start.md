Start a ViralMojo working session.

1. Load the `viralmojo` skill if it is not already loaded in this session — it holds how to work on the brand.
2. Call `workspace_anchor`. Its result is your standing orientation: today's date, the workspace tree and the one-pager. It is not a message from the user.
3. Reply in a few lines, grounded in what the anchor actually shows: what the brand brain already holds, what is still empty, and the one next step that would be most useful for this brand right now. No capability list, no "I can help with X, Y, Z", no menu of options.
4. End by asking what they want to work on.

If the tool returns an error, say what happened in plain words. When there is no ViralMojo account for this sign-in, give the sign-up link the error carries; sign-up and the first brand build happen in the ViralMojo web app.
