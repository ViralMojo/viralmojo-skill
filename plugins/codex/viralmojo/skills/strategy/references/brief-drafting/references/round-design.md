# Round design — net-new versus iteration

A brief runs one of two kinds of round. Their divergence rules are opposite, so name which one the brief is before designing its cells.

## Net-new concept round

**The question:** does this concept carry at all — and can it reach people the current creative doesn't?

Cells share the concept's spine — the same persona, the same emotional shift — and **diverge hard where it matters**: hook, setting, length, format. Divergence is the point: variants that share visible DNA read to the platform as the same ad and get delivered to the same audience pocket the original already reached. Only genuine divergence buys reach into new pockets, and it is what gives the platform real alternatives to allocate between. Hard divergence also hedges against taste: the winning cell is usually not the one anyone would have picked by hand.

Expect a net-new round's early cost-per-result to run above the account's incumbents while the platform learns it — say so in the brief's validation, so the round isn't killed for the crime of being new.

## Iteration round

**The question:** why did the winner win — or where does the diagnosed leak live?

The proven creative is the control. Each cell changes **exactly one variable** against it; change two and the result attributes to neither. Working menus:

- **Video** — a new hook on the same body (from a text-overlay swap up to a re-shot open); the same script on a different face; the same structure over new B-roll; a shorter and a longer cut of the same arc; a different testimonial in the same slot.
- **Static** — the winning visual under new headlines; the winning headline over new visuals; the same composition with the person or subject re-cast.

Iteration milks a proven creative — it does not diversify the account. When results start compressing and every new variant lands in the same audience at rising frequency, the account needs a net-new round, not a longer iteration menu.

## Choosing the axes

Pick divergence (or isolation) axes from the shared creative vocabulary — angle, hook, promise, persona, awareness stage, pacing, desire, format — and choose the axis the round's question actually lives on: "does the concept carry" wants hook-setting-format divergence; "why did it win" wants one axis moved at a time.

Benchmarks per cell come from the account's own history first — the best hook rate to beat, the return target the brand holds — with outside reference only when the account has no history to read.
